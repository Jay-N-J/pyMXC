What it costs. Starting a small Python program took 32 ms without the sandbox and 70 ms inside it on this computer (median of 5). That is paid once per program start, not while it runs.

Reading the middle column. pymxc's defaults block files, saved passwords, persistence, the network and reading the clipboard, and leave your environment variables alone so ordinary programs keep working. The strict column adds hide_secret_env=True and clipboard="none", which also stops the program from putting anything on the clipboard.

About environment variables. A sandboxed program receives your environment variables, which is how your own app gets its API key. hide_secret_env=True removes the ones whose names look like keys, tokens or passwords; it goes by name, so it does not hide ordinary variables or a secret kept under an unremarkable name. For commands you do not trust, pass an explicit env= with only what they need.

To let a program reach one service only, such as an LLM API, use network="hosts".
